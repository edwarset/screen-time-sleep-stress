# Screen Time, Sleep & Stress Research Website

Static website for GitHub Pages. Includes Assignment 7 and Assignment 8 interactive Plotly analysis.

## Deploy
1. Upload the **contents** of this folder to the root of your GitHub repository.
2. In Settings > Pages, select Deploy from a branch, main, /(root).
3. Open the Pages URL after deployment.

Assignment 8 uses Plotly from a CDN, so internet access is required for interactive charts.

The original research pages were restored from the latest available navigation files. Existing chart references have been pointed to available PNG visualizations.
